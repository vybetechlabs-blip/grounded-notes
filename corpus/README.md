# Lanternfish Consulting — Knowledge Base

**Everything in this folder is fictional.** Lanternfish Consulting, its staff,
its clients, its projects, and every number in these documents were invented as
a demo corpus for the grounded-notes RAG assistant. Any resemblance to real
companies or people is coincidental.

The corpus is deliberately written like a real consultancy's internal wiki —
cross-referencing SOPs, playbooks, project retrospectives, and FAQs — so that
retrieval quality questions ("which doc answers this?") have real teeth.

## Layout

| Folder      | Contents                                             |
| ----------- | ---------------------------------------------------- |
| `company/`  | Firm overview, services, pricing, roles, tooling     |
| `sops/`     | Standard operating procedures (onboarding → offboarding) |
| `playbooks/`| Delivery playbooks for common engagement types       |
| `retros/`   | Project retrospectives (fictional clients)           |
| `faq/`      | Client-facing and internal FAQs                      |
